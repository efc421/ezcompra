# EZCOMPRA Launch v1

Launch-focused React + Vite build for the first public EZCOMPRA catalog.

Included:
- Storefront + bilingual toggle
- Product search and categories
- Product detail pages with long description, specs, pros/cons
- Amazon affiliate disclosures
- Supabase database/storage/auth
- Admin add/edit/delete/publish
- AI content pipeline
- Amazon Creators API adapter ready to activate when credentials are available
- Vite multi-page production build for `index.html`, `admin.html`, and `product.html`

Run locally:
```
npm install
npm run dev
```

Build:
```
npm run build
```

See `LAUNCH-CHECKLIST.md` before publishing.
